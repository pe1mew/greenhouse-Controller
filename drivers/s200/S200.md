# SenseCAP ONE V2 S200 Wind Sensor — Driver Library

## Purpose

Thin Modbus RTU driver for the **Seeed SenseCAP ONE V2 S200** compact wind station.
Exposes wind speed (min/avg/max), wind direction (min/avg/max), and heating temperature
via a single `s200_read_measurements()` call.  An optional FreeRTOS task polls the
sensor on a configurable interval.

Reference: *SenseCAP ONE V2 Compact Weather Station User Guide*
(`documentation/Sensors/W-Sensecap-S200/SenseCAP_ONE_V2_Compact_Weather_Station_User_Guide.pdf`)

---

## Sensor Overview

| Property | Value |
|----------|-------|
| Model | SenseCAP ONE V2 S200 |
| Measurements | Wind speed (min/avg/max), wind direction (min/avg/max), heating temperature |
| Interface | Modbus RTU over RS-485 |
| Default slave address | **44** |
| Baud rate | 9600 bps |
| Frame format | 8 data bits, no parity, 1 stop bit (8N1) |
| Measurement function code | FC04 (Read Input Registers) |
| Configuration function code | FC03 / FC16 (Read/Write Holding Registers) |
| Register width | 32-bit signed integer across two 16-bit registers (big-endian word order) |
| Scale factor | ÷ 1000 for all measurements |

---

## Register Map

### Input Registers — FC04 (read-only sensor data)

All values are encoded as **int32** spanning two consecutive 16-bit registers.
Word order is big-endian: the high word occupies the lower address.
Decode: `value = (int32_t)(((uint32_t)regs[high] << 16) | regs[low])`

| Address | Name | Raw range | Engineering unit | Scale |
|---------|------|-----------|-----------------|-------|
| 0x0008–0x0009 | Minimum wind direction | 0 … 360 000 | ° | ÷ 1 000 |
| 0x000A–0x000B | Maximum wind direction | 0 … 360 000 | ° | ÷ 1 000 |
| 0x000C–0x000D | Average wind direction | 0 … 360 000 | ° | ÷ 1 000 |
| 0x000E–0x000F | Minimum wind speed | 0 … 60 000 | m/s | ÷ 1 000 |
| 0x0010–0x0011 | Maximum wind speed | 0 … 60 000 | m/s | ÷ 1 000 |
| 0x0012–0x0013 | Average wind speed | 0 … 60 000 | m/s | ÷ 1 000 |
| 0x001C–0x001D | Heating temperature | −40 000 … 85 000 | °C | ÷ 1 000 |

The driver reads the six wind channels in a single FC04 request (0x0008–0x0013, 12 registers)
and the heating temperature in a second FC04 request (0x001C–0x001D, 2 registers).

### Holding Registers — FC03/FC16 (configuration)

| Address | Name | Values | Default |
|---------|------|--------|---------|
| 0x1000 | Device address | 1–247 | 44 |
| 0x1001 | Baud rate code | 96 = 9600 bps, 192 = 19200, 384 = 38400, 576 = 57600, 1152 = 115200 | 96 |

## API Reference

### Status codes

```c
typedef enum {
    S200_OK        = 0,  /* Operation succeeded. */
    S200_ERR_COMM  = 1,  /* Modbus communication error (timeout / CRC / exception). */
    S200_ERR_PARAM = 2,  /* Invalid parameter (NULL pointer, slave_addr == 0). */
} s200_status_t;
```

### Measurement structure

```c
typedef struct {
    float wind_dir_min_deg;      /* Minimum wind direction  (°, 0–360) */
    float wind_dir_max_deg;      /* Maximum wind direction  (°, 0–360) */
    float wind_dir_avg_deg;      /* Average wind direction  (°, 0–360) */
    float wind_speed_min_ms;     /* Minimum wind speed      (m/s) */
    float wind_speed_max_ms;     /* Maximum wind speed      (m/s) */
    float wind_speed_avg_ms;     /* Average wind speed      (m/s) */
    float heating_temperature_c; /* Heater temperature      (°C, -40…85) */
} s200_measurement_t;
```

### Functions

#### `s200_read_measurements`

```c
s200_status_t s200_read_measurements(uint8_t slave_addr, s200_measurement_t *out);
```

Reads all seven channels.  Issues two FC04 requests:
1. 0x0008–0x0013 (12 registers) — wind direction and speed
2. 0x001C–0x001D (2 registers) — heating temperature

Returns `S200_ERR_PARAM` if `slave_addr == 0` or `out == NULL`.
Returns `S200_ERR_COMM` on any Modbus error.

#### `s200_task` (FreeRTOS, not available in `NATIVE_TEST` builds)

```c
void s200_task(void *pvParameters);
```

Periodic polling task.  Pass a pointer to a fully initialised `s200_task_param_t`
as `pvParameters`.  Updates `out_data` and `out_status` under `mutex` on every
`poll_interval_ms` tick.

## Usage Example

```c
#include "modbus_rtu.h"
#include "s200.h"

static s200_measurement_t g_meas;
static s200_status_t      g_status;
static s200_task_param_t  g_param = {
    .slave_addr       = S200_DEFAULT_ADDR,  /* 44 */
    .poll_interval_ms = 5000,
    .out_data         = &g_meas,
    .out_status       = &g_status,
    .mutex            = NULL,               /* created below */
};

void app_main(void) {
    modbus_init();
    g_param.mutex = xSemaphoreCreateMutex();
    xTaskCreatePinnedToCore(s200_task, "s200", 2048, &g_param, 5, NULL, APP_CPU_NUM);
}
```

## Hardware Wiring

| Signal | GPIO |
|--------|------|
| RS-485 TX (DI) | GPIO 17 |
| RS-485 RX (RO) | GPIO 18 |
| RS-485 DE+RE | GPIO 8 |

S200 cable colours (SenseCAP standard):
- Brown = RS-485 A+
- White = RS-485 B−
- Red = 9–30 V DC supply
- Black = GND
